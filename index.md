## 📊 Understanding the Metrics

The overlay displays core data points to help you identify performance issues.

*   **FPS (Frames Per Second):** This number shows how smooth your game feels. Higher numbers mean smoother motion. A number below 30 often causes stuttering.
*   **CPU Usage:** This tracks how much work your processor handles. If this number stays near 100%, your computer may struggle to launch other programs.
*   **GPU Temperature:** This measurement tells you how hot your graphics card gets. Keep this below 85 degrees Celsius for safe operation.
*   **RAM Usage:** This shows how much memory your games require. If your RAM usage hits your total limit, your system will slow down.

## 🧹 Troubleshooting Common Issues

**The overlay does not appear.**
Ensure you run the game in Windowed or Borderless Windowed mode. Some games block overlays in Fullscreen mode. Close the monitoring tool and restart it if the issue persists.

**The frame rate seems low.**
Check if other programs run in the background. Web browsers and video players consume resources that your games need. Close these programs to increase your performance.

**The font size is too small.**
Enter the settings menu inside the application. Look for the "Display" tab. Change the text scale percentage to make the numbers easier to read.
